# 异常与恢复

- 服务未开放或收费模式不是fixed：停止新任务，提供官网及客服。
- API Key失效：提示填写有效的同一种API Key，不自动换成现金付款。
- 上传中断：先查原会话上传列表，恢复未verified文件，不创建新任务。
- 预检未完成、无法计量、压缩包需审批或格式不支持：说明状态并等待或请用户调整材料；不能跳过后直接启动。
- QUOTE_EXPIRED / QUOTE_INPUT_CHANGED：在工具内重新获取报价并核对文件摘要与总价。材料范围发生变化时重新确认材料；访客只在有效二维码就绪时展示更新后的价格，API Key 账户在冻结前确认更新后的报价。
- ACTIVE_REVIEW_EXISTS：访客身份已有任务时恢复原会话，处理原未付任务，确认到账后即可开下一单。账户任务额度由积分冻结控制，余额不足或欠款按对应错误处理。
- 新访客单 (`before_review`) 在免费预检后用有效报价申请付款单，付款前没有运行编号。收到“等待付款”时恢复同一付款单。到账后由服务端启动一次，Agent 只需查询原会话。
- 付款未知或提交响应丢失：查询原单、保留幂等键，不换单，不根据用户口述解锁。
- REPORT_PAYMENT_REQUIRED（402）：完成原账单或账户充值，结清后只解锁，不重跑。
- 邮件失败：已结清报告仍可下载；检查本次邮箱，可联系客服重试。
- REPORT_VERSION_UNSUPPORTED / 报告格式不受支持：不转换旧报告，不猜测新结构；说明此版本不在当前技能支持范围，保留原任务记录。
- 图像核验或必要检索失败：按服务器状态继续恢复或说明失败，不能伪称已看图、不能自行编造结论。
- 任务失败、取消或运行超时：已付时跟进原路退款，给出 UUID 及可见状态，不编造报告。
- 会话已过保留期：说明资料不可再下载，不能谎称有恢复副本；用户要重新审查时确认材料后创建新任务。
